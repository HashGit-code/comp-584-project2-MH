# Golden State Routes — COMP 584 Project 2

This project is a responsive California road trip guide built with CSS Flexbox. It replaces the starter dog theme with original destination content and local images.

## Flexbox requirements included

- Six distinct rows using flexible columns
- Four equal cards in the first desktop row
- Two equal cards in the second desktop row
- A `1 + 3` column layout in the third desktop row
- One four-column-wide feature in the fourth row
- A `1 + 2 + 1` layout in the fifth desktop row
- Reordering with the CSS `order` property on tablet screens
- A unique sixth row with five flexible checklist items
- Responsive tablet and mobile layouts using media queries
